# GPT 设计的 3D 模型

本仓库保存 GPT 辅助设计的 3D 模型、各版本工程文件、STEP 导出、预览和相关脚本。以下索引介绍每个模型及其版本日期。

日期依据本地工程、STEP 和生成脚本的文件时间记录，表示该版本的生成或最近保存日期，并非经独立核实的设计完成日期。尺寸单位为毫米。每个目录包含 FreeCAD 工程（`.FCStd`）、STEP 模型和预览图；部分含备份（`.FCBak`）及几何检查记录（`validation.json`）。

## 透明对称弧面罩

- [v1 外形样机](透明对称弧面罩_v1/) — **2026-11-13**：约 42 × 38 × 22，壁厚 1.2，圆角半径 8；上下对称，接口侧有开口。固定结构和接口空间需实物确认。
- [v2 定位版](透明对称弧面罩_v2_定位版/) — **2026-11-14**：增加 PCB 托台、压脚和限位筋；侧向名义间隙 0.2，上下各约 0.1。上下壳锁合结构尚未设计。
- [v3 铁柱槽](透明对称弧面罩_v3_铁柱槽/) — **2026-11-14**：增加宽 2.2 的贯通 U 形槽，适配直径 2 的参考铁柱，缩小接口开口；接口名义间隙约 0.25。锁合和密封仍需解决。

球形外壳各版本的 FCStd 最后保存时间晚于对应 STEP 导出时间；本次没有重新导出，不能假定两者完全一致。STEP 不含 PCB 和参考铁柱。几何检查记录不等于实物验证，打印、装配、插拔、胶封及发泡工艺均需试验。

## 脚本与分析

根目录的 `build_light_cover_v*.py`、`build_sphere_*.py` 是对应模型的生成脚本，`preview_*.py` 用于生成预览；`analyze_diameter_options.py` 和 `diameter_optimization_analysis.json` 记录直径方案分析。脚本依赖 FreeCAD、原始 PCB 模型以及本机固定路径；重新运行前应核对路径和已有输出，避免覆盖。其他软件和文档不属于本索引范围。
